> 회원 여러분이 더 안전하고 편리하게 서비스를 이용하실 수 있도록 제공되는 기능들을 안내합니다.

---

## 1. 로그인 방법

서비스는 다양한 방법으로 로그인할 수 있습니다.

### 아이디 / 비밀번호 로그인

가입 시 등록한 아이디와 비밀번호로 로그인합니다.
"로그인 상태 유지"를 선택하면 브라우저를 닫아도 로그인이 유지됩니다.

### 카카오 / 네이버 로그인

별도의 아이디와 비밀번호 없이 카카오 또는 네이버 계정으로 간편하게 로그인할 수 있습니다.
처음 소셜 로그인을 이용하는 경우 서비스 계정과 자동으로 연동됩니다.

---

## 2. 본인 인증 (OTP)

로그인할 때 본인 확인을 위해 **일회용 인증 코드(OTP)**를 사용할 수 있습니다.
계정을 더 안전하게 보호하는 기능으로, **회원가입 시 선택한 인증 수단**으로 코드가 발송됩니다.

### 인증 수단

| 수단 | 설명 |
|------|------|
| 문자(SMS) | 등록된 휴대폰 번호로 6자리 코드 발송 |
| 이메일 | 등록된 이메일 주소로 6자리 코드 발송 |

> 가입 시 인증 수단을 선택하지 않은 경우 OTP 인증 없이 로그인됩니다.

- 인증 코드는 발송 후 **5분간** 유효합니다.
- 코드를 받지 못한 경우 화면의 **재발송** 버튼을 클릭하세요.
  (30분 내 최대 5회 발송 가능)

---

## 3. 회원가입

### 가입 절차

1. 이용약관에 동의합니다.
2. 아이디, 비밀번호, 이름, 이메일, 휴대폰 번호, OTP 수단을 입력합니다.
   이메일과 휴대폰 번호는 각각 문자(SMS)로 전송된 인증 코드로 본인 확인이 필요합니다.
3. 가입이 완료됩니다.

### 이용약관 동의

| 항목 | 필수 여부 |
|------|-----------|
| 서비스 이용약관 | 필수 |
| 개인정보 수집 및 이용 동의 | 필수 |
| 만 14세 이상 확인 | 필수 |
| 개인정보 수집 및 이용 동의 (선택) | 선택 |
| 마케팅 수신 동의 (이메일 · SMS · 푸시) | 선택 |

선택 항목은 동의하지 않아도 가입과 서비스 이용에 제한이 없습니다.

---

## 4. 아이디 · 비밀번호 찾기

### 아이디 찾기

가입 시 등록한 이메일 또는 휴대폰 번호로 본인 인증을 하면 아이디를 확인할 수 있습니다.

### 비밀번호 재설정

1. 로그인 화면에서 **비밀번호 찾기**를 클릭합니다.
2. 아이디를 입력한 후 이메일 또는 문자로 인증 코드를 받습니다.
3. 인증 완료 후 새 비밀번호를 설정합니다.

---

## 5. 내 정보 관리

로그인 후 **내 계정** 메뉴에서 아래 정보를 관리할 수 있습니다.
(`https://{keycloak-host}/realms/{realm}/user-profile?return_uri={return-url}`)

### 기본 정보 확인 및 수정

이름, 이메일, 휴대폰 번호 등 등록된 정보를 확인하고, 변경이 필요한 경우 수정할 수 있습니다.
이메일 또는 휴대폰 번호 변경 시 본인 인증이 필요합니다.

### 비밀번호 변경

현재 비밀번호를 확인한 후 새 비밀번호로 변경할 수 있습니다.

### 마케팅 수신 동의 변경

해당 기능은 곧 제공될 예정입니다.

### 회원 탈퇴

**내 정보** 화면 하단의 **회원탈퇴**를 클릭하면 계정을 탈퇴할 수 있습니다.

1. 본인 확인을 위해 비밀번호를 입력합니다.
2. 탈퇴 시 유의사항을 확인한 후 **탈퇴하기**를 클릭합니다.
3. 탈퇴가 완료되며, 처리 결과가 등록된 이메일로 안내됩니다.

탈퇴 후에는 해당 계정으로 다시 로그인할 수 없으며, 등록된 이메일과 휴대폰 번호 정보는 즉시 파기되어
다른 계정 가입 시 바로 재사용하실 수 있습니다. 서비스를 다시 이용하시려면 새로 회원가입해야 합니다.

## 6. 외부 계정 연동 로그인 (Identity Provider)

Keycloak Identity Provider(IDP) 기반으로 다양한 외부 계정을 로그인 수단으로 연동할 수 있습니다.
별도의 아이디·비밀번호 없이 이미 사용 중인 외부 계정으로 간편하게 로그인할 수 있습니다.

### 지원 IDP 유형

| 유형 | 제공사 | 설명 |
|------|--------|------|
| 소셜 로그인 | 카카오 | 카카오 계정으로 간편 로그인 |
| 소셜 로그인 | 네이버 | 네이버 계정으로 간편 로그인 |
| 간편 인증 | KG이니시스 | 이니시스 기반 간편 인증 로그인 (목업 제공) |

> 소셜 로그인(카카오·네이버)은 현재 제공 중이며,
> 간편 인증(이니시스·통신사)은 이니시스 기반 목업을 포함한 확장 아키텍처가 제공되어 추가 연동이 가능합니다.

### 기존 계정과의 연동

로그인 화면에서 외부 계정 버튼을 클릭하면 자동으로 연동이 진행됩니다.
기존에 아이디/비밀번호로 가입한 회원도 로그인 화면에서 외부 계정으로 연동 후 간편하게 로그인할 수 있습니다.
연동 후에도 기존 아이디/비밀번호 로그인은 그대로 유지됩니다.

## 7. 장기 미접속 계정 보호

오랜 기간 로그인하지 않은 계정은 **개인정보 보호를 위해 자동으로 보호 상태**로 전환됩니다.

### 기본 적용 기간

| 항목 | 기본값 | 설명 |
|------|--------|------|
| 휴면 전환 기준 | **365일** | 마지막 로그인으로부터 1년간 미접속 시 보호 상태로 전환 |
| 휴면 전환 사전 안내 | **전환 30일 전** | 보호 상태 전환 예정 안내 메시지 발송 |
| 계정 삭제 기준 | **보호 상태 후 90일** | 보호 상태에서도 미접속 시 삭제 대상으로 지정 |
| 삭제 사전 안내 | **삭제 30일 전** | 계정 삭제 예정 안내 메시지 발송 |

> 위 기간은 서비스 운영 정책에 따라 변경될 수 있습니다. 변경 시 사전에 안내 드립니다.

### 보호 상태 전환 전 안내

전환 예정일 이전에 등록된 이메일 또는 휴대폰으로 **사전 안내 메시지**가 발송됩니다.
안내를 받으신 후 로그인하시면 보호 상태로 전환되지 않습니다.

### 보호 상태에서 로그인하는 방법

보호 상태 계정은 로그인 시 본인 확인이 필요합니다.

1. 로그인하면 계정 보호 안내 화면이 나타납니다.
2. 이메일 또는 문자로 발송된 **인증 코드(6자리)**를 입력합니다.
3. 인증 완료 후 계정이 즉시 정상화되어 서비스를 이용하실 수 있습니다.

### 장기간 방치 시 계정 삭제

보호 상태에서도 일정 기간 이상 접속하지 않으면 계정이 **영구 삭제**될 수 있습니다.
삭제 전에도 안내 메시지가 발송되며, 안내를 받으신 후 로그인하시면 삭제를 막을 수 있습니다.

## 8. 자주 묻는 질문

**Q. 비밀번호를 잊어버렸어요.**
로그인 화면의 **비밀번호 찾기**를 클릭하세요. 이메일 또는 문자 인증으로 새 비밀번호를 설정할 수 있습니다.

---

**Q. 인증 코드가 오지 않아요.**
스팸 메일함 또는 통신사 스팸 필터를 먼저 확인해 주세요.
그래도 받지 못하셨다면 화면의 **재발송** 버튼을 눌러 다시 요청하세요 (30분 내 5회 제한).
이후에도 해결되지 않으면 고객센터에 문의해 주세요.

---

**Q. 카카오 / 네이버로 로그인하고 싶어요.**
로그인 화면 하단의 소셜 로그인 버튼을 클릭하세요.
처음 이용 시 약관 동의가 필요할 수 있습니다.

---

**Q. 계정이 잠겼어요.**
비밀번호를 여러 번 잘못 입력하면 계정이 일시적으로 잠길 수 있습니다.
잠금은 일정 시간이 지나면 자동으로 해제되며, 즉시 해제가 필요한 경우 고객센터에 문의해 주세요.

---

**Q. 오랫동안 로그인을 안 했더니 계정이 이상해요.**
장기 미접속으로 계정이 보호 상태로 전환된 것입니다.
로그인 후 이메일 또는 문자로 받은 인증 코드를 입력하시면 바로 정상 이용이 가능합니다.
→ [7. 장기 미접속 계정 보호](#7-장기-미접속-계정-보호) 참고

---

**Q. 마케팅 문자 / 이메일 수신을 중단하고 싶어요.**
**내 계정 → 마케팅 수신 동의** 메뉴에서 채널별로 수신을 거부하실 수 있습니다.
